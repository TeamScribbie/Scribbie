HOW TO USE:
═══════════════════════════════════════════════════════════════

1. Open your game (WordFeast or Memory Game)
2. Open Browser Console (F12 → Console tab)
3. Look for these logs:

   🎵 === WORDFEAST AUDIO DEBUG ===
   🎵 RAW Question Data: {...}
   🎵 RAW Choices Data: [...]
   🎵 CONSTRUCTED URLs:
      Question Audio: https://...
      Choice Audios: [...]
   ✅ Question audio HTTP 200: https://...
   OR
   ❌ Question audio FAILED: https://... [error message]

═══════════════════════════════════════════════════════════════
WHAT TO CHECK:
═══════════════════════════════════════════════════════════════

SCENARIO 1: You see "NO AUDIO" everywhere
├─ Problem: Backend not sending audio paths
├─ Cause: Files not uploaded OR database not storing paths
└─ Solution: Check backend file upload and database

SCENARIO 2: URLs shown but all have ❌ FAILED with "404"
├─ Problem: Files don't exist on server
├─ Cause: Upload failed OR files in wrong directory
└─ Solution: Check server file storage

SCENARIO 3: URLs shown but ❌ FAILED with "CORS" or "403"
├─ Problem: Server blocking access to files
├─ Cause: Spring Boot not configured to serve static files
└─ Solution: Configure static resource handling

SCENARIO 4: URLs shown with ✅ HTTP 200 but no sound plays
├─ Problem: Code issue with audio player
├─ Cause: Browser can't play format OR volume is 0
└─ Solution: Check audio format and player code
